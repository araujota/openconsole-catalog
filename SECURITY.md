# Security policy

Report vulnerabilities privately through GitHub Security Advisories at
https://github.com/araujota/openconsole-catalog/security/advisories/new.
Do not open a public issue with exploit details or uploaded private bundles.

The `v0.1` development preview is supported. Static analysis is not a sandbox;
EFI games remain trusted native code. Provider credentials belong only in
Convex, Vercel, or protected CI configuration.
